# FLRocket

FLRocket hilft dir, Freelancer-Mods mit verfügbaren Übersetzungen zu spielen. Du musst keine Dateien von Hand patchen: herunterladen, entpacken, Sprache auswählen, Spiel starten.

## Schnellstart

1. Lade die aktuelle ZIP aus den [FLRocket Releases](https://github.com/flathack/FLRocket/releases/latest) herunter.
2. Entpacke die ZIP direkt in den Hauptordner deiner Freelancer-Mod-Installation.
3. Wichtig: `FLRocket.exe` und `WebView2Loader.dll` müssen nebeneinander liegen.
4. Starte `FLRocket.exe`.
5. Wähle im Launcher die gewünschte Sprache.
6. Klicke auf `Übersetzung vorbereiten`.
7. Starte danach das Spiel über FLRocket.

Der richtige Spielordner ist der Ordner, in dem auch der Ordner `EXE` liegt.

## Aktuell verfügbare Übersetzungen

| Mod | Sprache |
| --- | --- |
| Freelancer Crossfire | Deutsch |
| Freelancer Reforged | Deutsch |
| Erkannte Mods | Original |

`Original` bedeutet: keine Übersetzung verwenden und das Spiel in seiner normalen Sprache starten.

Wenn eine Sprache im Launcher nicht angezeigt wird, gibt es dafür aktuell noch kein Übersetzungspaket.

## Hinweise

- FLRocket ist ein Community-Launcher und kein offizieller Crossfire Launcher.
- Für Crossfire-Updates und Multiplayer bleibt der offizielle Crossfire Launcher zuständig.
- FLRocket ist vor allem dafür gedacht, Übersetzungen komfortabel vorzubereiten und das Spiel direkt zu starten.
- Bei Problemen kannst du jederzeit wieder `Original` auswählen.
